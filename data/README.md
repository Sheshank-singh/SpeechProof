# SpeechProof Dataset Directory

This directory contains the contrastive speech evaluation dataset and benchmark artifacts for SpeechProof.

## Contents

- `manifest.csv`: The metadata manifest defining all 10 speech audio clips, their 5 matched pair pairings (`pair_id`), delivery type (`ideal` vs `flawed`), script IDs, durations, intended delivery flaws, and acoustic annotation parameters.
- `benchmark_results.json`: Full empirical evaluation report generated by `scripts/evaluate_benchmark.py`, documenting 100% flaw grounding accuracy, precision, recall, F1 score, metric deltas, and score separation across all pairs.
- `examples/`: Directory containing the 10 genuine 16 kHz WAV audio files:
  - `P01_ideal.wav` & `P01_flawed.wav` (Elevator Pitch: Fluency & Fillers)
  - `P02_ideal.wav` & `P02_flawed.wav` (Cloud Keynote: Pausing & Awkward Silences)
  - `P03_ideal.wav` & `P03_flawed.wav` (Sensor Launch: Pacing & Rushed Speech)
  - `P04_ideal.wav` & `P04_flawed.wav` (Exec Briefing: Vocal Variation & Monotone Pitch)
  - `P05_ideal.wav` & `P05_flawed.wav` (Customer Advisory: Volume Consistency & Fading)

To regenerate or evaluate this dataset from scratch:
```bash
python scripts/generate_dataset.py
python scripts/evaluate_benchmark.py
```
